# P001 — Define the original T8103 target

**Status:** complete. **Review date:** 2026-10-23. **Branch:** `main`.

**Selected target:** Apple M1 / T8103 / H13G; Mac mini (M1, 2020), board J274.

## Requirement and delivered evidence

The unchanged roadmap requirement is to record M1/H13G, J274 and excluded variants in the architecture charter, with every project entrypoint identifying the same first SoC and board.

| Acceptance item | Evidence |
|---|---|
| Original SoC and board are unambiguous | [Target charter](../ARCHITECTURE.md#p001-target-charter), including separate marketed, internal, SoC, board, model and product identifiers. |
| Excluded variants are explicit | Charter and `hardware/t8103.json` list T6000/T6001/T6002, J293/J313/J456/J457, later M-series and A-series; all other boards are excluded by default. |
| Entrypoints agree | `tools/validate_target.py` validates the structured target and one visible declaration in each of the six enumerated overview/setup documents. |
| Changes cannot silently alter the declared first target | `tests/test_target.py` exercises incorrect identities, compatible ordering, missing sources, malformed input, contradictory exclusions and all six entrypoints. |
| Claims are sourced | [Identity references](../REFERENCES.md#p001-identity-evidence), with immutable Linux and Asahi revisions and the Apple support-page review date. |
| Check runs for future changes | `.github/workflows/verify.yml` runs the new validator before the existing metadata and unit checks. |
