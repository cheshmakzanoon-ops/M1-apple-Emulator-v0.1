## Three verification passes

1. **Requirement and source review.** Mapped every P003 obligation to the contract/procedure/tooling, checked the Linux boot and driver interfaces against primary sources, and compared all original phase and gate definitions with the starting revision. No later phase was promoted to complete.
2. **Executable positive and negative checks.** Ran the full suite and all five validators. Tests cover alternate roots/working directories, malformed and missing files, hidden/duplicated publication, source-profile boundaries, raw IRQ formatting and both shell interactions. Synthetic valid fixtures are deliberately labelled as synthetic.
3. **Independent audit and clean-tree reproduction.** A separate reviewer checked acceptance, code and source-derived format assumptions. The final staged Git tree was exported into a fresh temporary directory and the full suite, five validators and shell syntax checks were rerun there, excluding untracked files and local build state.

The audit produced actual corrections before completion:

- Replaced the incorrect direct tty-driver lookup with physical-UART ancestry verification; added direct-parent and nested serial-core fixtures plus invalid/sibling/broken-link cases.
- Required terminal-restoration failures to emit `G4-ERROR`, and guarded the returned-shell command on the probe's zero exit status.
- Rejected malformed hardware-IRQ/descriptor fields and separated the source-format unsigned 32-bit IRQ counters from unsigned 64-bit hardware IRQ identifiers.
- Corrected the fatal-error matcher so `DEBUG:` does not accidentally match `BUG:`.
- Completed the BusyBox dependency inventory, including `tr`, `readlink -f`, timed ash input and 64-bit arithmetic.

## Deviations and limitations

No phase-scope deviation. P004–P365 remain unchecked; P194's artifact-loader enforcement, P196–P198's actual builds, P209's live runner, P210's G4 certification and P363's independent reproduction remain future work.

P003 freezes a source-observable profile, not a working emulator or proven kernel configuration. No fabricated CPU name, RAM size, load address or timer frequency was introduced. The hardware map and generic smoke guest/runner are unchanged. No Apple firmware, proprietary images, physical-machine captures or new MMIO implementation were added.

The offline checker cannot authenticate fabricated captures, prove host event timing, cold startup or input hashes, or establish causal IRQ routing from strings/counters. UART counts can include TX; G2/G3 RX traces remain mandatory. The future live runner and independent reviewer must establish all those facts before G4 can be accepted. The policy validator checks the explicit contract and its publication; coordinated prose changes still require engineering review.
